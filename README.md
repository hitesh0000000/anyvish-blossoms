# ANYVISH BLOSSOMS

Mobile-friendly storefront for handcrafted chenille flowers, with a custom bouquet builder, shopping bag, and WhatsApp ordering.

## Live site

The site is published with GitHub Pages after each push to `main`.

## Local preview

Run `npm ci` and `npm run build`, then open `index.html` in a browser. Flower photography, logo artwork, and compiled styles are served locally; fonts and icons are loaded from Google Fonts.

The transparent source logo is `assets/brand-logo.png`; `assets/brand-wordmark.png` and `assets/favicon.png` are its storefront-ready variations.

## Publish

The included GitHub Actions workflow deploys the repository to GitHub Pages. Enable Pages with **GitHub Actions** as the build and deployment source in the repository settings.
