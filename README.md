# ANYVISH BLOSSOMS

Mobile-friendly storefront for handcrafted chenille flowers, with a custom bouquet builder, shopping bag, and WhatsApp ordering.

## Live site

The site is published with GitHub Pages after each push to `main`.

## Local preview

Open `index.html` in a browser. Product photography, fonts, and Tailwind CSS are loaded from their configured external CDNs.

## Publish

The included GitHub Actions workflow deploys the repository to GitHub Pages. Enable Pages with **GitHub Actions** as the build and deployment source in the repository settings.
